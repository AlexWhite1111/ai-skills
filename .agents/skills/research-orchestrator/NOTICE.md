# Method Note

This skill was inspired by the public task prompt in Shanmu Jin's Crouzeix-conjecture repository:

https://github.com/jinshanmu/CrouzeixConjecture/blob/main/crouzeix_conjecture_prompt.txt

The source prompt's central orchestration ideas include dynamic multi-agent allocation, early route independence, approach-family registration, blocked-route handling, delayed cross-pollination, concrete deliverables, and adversarial checking.

This repository does not reproduce that task prompt as a domain-specific proof request. It generalizes and extends the orchestration method with an epistemic firewall, explicit state model, dual-track truth handling, finite-budget stopping, provenance, verification levels, reusable role briefs, and behavioral evaluations.
